¿Cómo conectar tu propia base de datos PostgreSQL?

  1. Crea tu base de datos en PostgreSQL (Local, Supabase, Neon o Docker) con CREATE DATABASE visor3d;.
  2. Ejecuta el script SQL incluido en server/schema.sql.
  3. Abre el archivo .env y coloca tu URL de conexión:
DATABASE_URL=postgresql://usuario:password@localhost:5432/visor3d

* Mientras no configures la base de datos externa, los datos se guardan de forma segura en el archivo local data/database.json sin interrumpir tu trabajo.
